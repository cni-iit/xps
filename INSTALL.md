# Installation instructions

Everything has been developed and tested on an environment with `python 3.13.5`.

## Prerequisites

A working installation of Anaconda.

## Step 0: Initialize Conda Environment

Create a new environment with Python.

```bash
conda create --name xps python==3.13.5
```

Activate the environment

```bash
conda activate xps
```

## Step 1: Install the requirement libraries

```bash
pip install -r requirements.txt
```
